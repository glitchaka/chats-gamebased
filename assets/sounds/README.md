# UI sound slots

The app looks for these optional MP3 files next to the executable:

- `ui-click.mp3` — button/send click
- `incoming.mp3` — incoming text message
- `sticker.mp3` — sticker sent/received

If a file is absent, the app falls back to a short generated tone.

SoundInstants pages can be used as a source for personal/non-commercial testing, but their terms state that redistribution/republication of site content requires authorization. Keep downloaded files local unless you have permission to redistribute them.
